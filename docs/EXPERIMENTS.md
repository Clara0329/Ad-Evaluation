## 3. 直接替换失败实验

将未经尺度校准的候选值直接替换旧 `center_focus` 后：

| 维度 | 平均变化 |
|---|---:|
| persuasion | -7.6528 |
| arousal | -8.6111 |
| trust | 0 |
| attention | -12.8264 |
| memory | -2.9896 |
| total | -6.4160 |

注意力绝对变化 ≥10：209/288；总分绝对变化 ≥5：215/288。

结论：TranSalNet 原始分布与旧 OpenCV 中心特征的尺度不同，不能直接替换；且旧中心特征同时影响说服度、唤醒度、注意力和记忆度，因此整体替换风险过高。

## 4. 场景分位数校准

使用中心显著度到旧中心特征的分位数映射，仅生成注意力候选值。样本数达到20的场景使用场景映射；小样本场景使用全局回退。

同批校准结果：

- 注意力变化均值：0.0347
- 中位数：0
- 范围：-9 至 9
- 注意力绝对变化 ≥10：0
- 总分变化均值：0.0069

## 5. 五折场景分层折外验证

- 样本：288
- 折数：5
- 注意力变化均值：-0.0764
- 中位数：0
- 范围：-8 至 9
- 注意力绝对变化 ≥5：19
- 注意力绝对变化 ≥10：0
- 总分变化均值：-0.0153
- 总分绝对变化 ≥2：0

解释：该验证证明校准映射具有折外尺度稳定性，但不能证明候选注意力具有更高心理效度。

## 6. 下一阶段外部验证

推荐独立外部集：

```text
12个主题 × 2个全新Prompt × 4个模型 × 1张 = 96张
```

要求：

- Prompt 和图片均未参与现有校准；
- 四模型使用相同核心 Prompt；
- 不因“难看”进行结果筛选；
- 隐藏模型名称后进行人工评价；
- 三位评分者独立完成五维 1—5 分评价。

统计：ICC 或 Krippendorff's Alpha、Spearman、MAE、RMSE、同 Prompt 第一名命中率和排序相关。
