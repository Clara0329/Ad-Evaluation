# 数据集与生成协议

## 1. 数据目标

研究对象包括广告海报、电商主图、短视频封面、校园活动、教育培训、公益、运动健身、科技创新和旅游宣传等视觉内容。

跨模型比较目标包括：

- Midjourney
- ChatGPT 图像生成
- 豆包
- Stable Diffusion

## 2. 公平生成协议

同一 Prompt 在不同模型中保持核心语义一致。每张图片至少记录：

- 图片编号、成员编号、主题类别、Prompt编号；
- 中文任务描述、英文 Prompt；
- 生成模型、模型版本、生成时间；
- 文件名、路径、尺寸；
- Seed、Steps、CFG、Sampler、Negative Prompt；
- 参数备注、生成状态、人工筛选结果和后处理说明。

平台不提供的参数填写 `N/A（平台未提供）`，禁止推测或补写。

## 3. 固定样本与方法复现

生成模型具有随机性，在线模型也可能更新。因此复现分为：

1. **样本复现**：公开论文实际使用的冻结原图和 SHA256；
2. **方法复现**：公开 Prompt、模型版本、日期、参数和采样规则；
3. **结论复现**：重新采样后比较模型均值、方差和统计趋势。

## 4. 数据划分

必须按 Prompt 整组划分，不能把同一 Prompt 的图片随机分入不同集合：

- `dev`：允许查看和修改；
- `regression`：检查版本回归；
- `holdout`：版本冻结后一次性打开；
- `external`：未参与任何校准的独立验证集。

同一 Prompt 在所有模型中必须属于同一划分。

## 5. GitHub 数据策略

代码仓库不直接提交模型权重、缓存、临时输出和完整大规模原图。推荐：

- 仓库内保留小型公开样本、划分文件、数据卡和校验值；
- 完整冻结数据集通过 GitHub Release、学校存储或数据平台发布；
- 仓库中提供稳定下载说明和 SHA256；
- 不把隐私信息、未获授权商业素材或问卷原始身份信息公开。

## 6. 元数据建议

统一维护一个 `AIGC视觉心理效应实验总表.xlsx`，包括：

1. 图片生成记录；
2. 实验索引；
3. 客观标注；
4. 系统结果汇总；
5. 人工心理评分。
