# 五维评分规则

## 1. 总体说明

评分引擎版本：`scene_category_source_aware_v3.1`。

五维分数均限制在 0—100，总分当前为五维算术平均。规则权重是文献和广告心理理论启发的工程初值，必须通过独立人工评价进行最终校准。

## 2. 消费说服度

主要证据：

- 核心主体是否明确；
- 卖点数量及可见性；
- 价格、促销、活动节点；
- CTA；
- 品牌或主办方身份；
- 目标受众；
- 中心焦点。

不同场景的说服机制不同。例如，电商广告更依赖价格、促销和 CTA；品牌广告更依赖品牌身份、情绪和主体呈现；活动海报更依赖活动名称、时间地点和参与指令。

## 3. 情绪唤醒度

主要证据：

- 饱和度与对比度；
- 中心焦点；
- 情绪语义强度；
- 注意元素数量；
- 部分场景的质量特征。

该维度描述视觉刺激和情绪强度，不等同于情绪正负方向。

## 4. 信任度

主要证据类别：

- 品牌身份；
- 官方渠道；
- 透明价格；
- 具体信息；
- 真实场景、参数或评价；
- 权威背书；
- 活动时间、地点与主办方；
- 图像质量与风险安全。

信任证据按类别去重，不因模型重复生成同义句而重复加分。

## 5. 注意力吸引度

正式规则主要使用：

- 对比度；
- `center_focus`；
- 注意元素数量；
- 饱和度；
- 布局复杂度与场景理想值的平衡；
- 质量特征。

短视频封面使用单独配置，强调对比、焦点和强注意元素。

TranSalNet 候选只替换注意力计算中的中心证据，其他四维保持正式值，并输出独立候选总分。正式结果不被覆盖。

## 6. 记忆留存度

按证据类别计算：

- 品牌；
- 活动名称或口号；
- 数字符号；
- 独特主体；
- 视觉符号；
- 色彩风格；
- 情绪；
- 中心焦点；
- 布局。

## 7. 场景配置

各场景评分函数位于 `modules/score_engine.py`：

| 场景 | 函数 |
|---|---|
| 电商商品广告 | `_score_ecommerce` |
| 品牌广告 | `_score_brand_ad` |
| 活动宣传海报 | `_score_event_poster` |
| 短视频封面 | `_score_video_cover` |
| 教育校园宣传 | `_score_education` |
| 公益宣传 | `_score_public_welfare` |
| 旅游宣传 | `_score_travel` |
| 其他 | `_score_general` |

## 8. 使用边界

- 不根据单张图片的“看起来合理”调整权重；
- 不用错误识别后的分数反向修补证据；
- 先验证客观证据，再校准心理分数；
- 所有正式权重变更必须记录版本、开发集和盲测结果。
